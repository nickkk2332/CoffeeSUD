# Optional composed abilities

Copy `modules/` and `compositions/` into a separate deployment. Select
`abilities.composition`, validate with `WORLD COMPOSITIONS CHECK`, and grant
`Skill_Compose` through your progression system. See the
[installation and cookbook](../../15-ability-composition.md).

Ember bolt has three supports: chaining, lingering fire, and more damage at
higher cost. The pack does not change the default world or grant abilities.
